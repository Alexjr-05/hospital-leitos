# 🏥 Sistema Hospitalar UMC

Sistema de gestão hospitalar desenvolvido para monitoramento e controle de leitos em tempo real.

## 📋 Sobre o Projeto

O Sistema Hospitalar UMC foi criado para auxiliar equipes hospitalares no gerenciamento de leitos, permitindo acompanhar ocupação, disponibilidade e indicadores operacionais de forma simples e intuitiva.

O projeto está sendo desenvolvido como parte dos estudos em desenvolvimento web, utilizando Node.js, MySQL e tecnologias frontend.

## 🛠️ Instalação

Clone o projeto:

```bash
git clone https://github.com/Alexjr-05/hospital-leitos.git
```

Instale as dependências:

```bash
npm install
```

Crie um arquivo `.env`:

```env
DB_HOST=localhost
DB_USER=root
DB_PASSWORD=sua_senha
DB_NAME=hospital_umc
```

Inicie o servidor:

```bash
node server.js
```
